# CLAUDE.md

## 프로젝트 개요
HTML, Tailwind CSS, JavaScript, Lucide 아이콘을 이용해 웹페이지를 만든다.

## 기술 스택
- HTML
- Tailwind CSS
- JavaScript (바닐라)
- Lucide 아이콘

## 작업 규칙
- 사용자가 명시적으로 특정 API나 라이브러리를 사용하라고 지시하면 그대로 사용한다.
- 작업 중 위 기술 스택 외에 API나 라이브러리가 필요하면, 도입 전에 반드시 사용자에게 확인을 받는다.
- 작업 중 문제가 발생하면 단순히 "안 된다"고 답하지 말고, 가능한 해결 방법을 함께 제시한다.
